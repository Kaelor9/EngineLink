EngineLink 0.11.9: reports itself.

- **EngineLink sends its own Wi-Fi report to GitHub.** With a GitHub token that may only create issues (saved under Diagnostics → Wi-Fi), the board files its network report as an issue in Kaelor9/EngineLink: after a router loss (as soon as it is back on the router with internet), after its web server had to restart itself, and when you tap "Send report now". The router name is removed because the repository is public; the token is never shown or included. At most one report every 30 minutes and 10 a day (except when sent by hand).
- **The report is always reachable at `http://<board address>:81/report`.** That small server is separate from the main web server, so the report can be read even when the main page stops answering, without switching the router off.
- Correction: 0.11.7 described "WPA2 first", but the ESP32 Wi-Fi library in use ignores the setting that would do it (PMF "capable" is deprecated and always on), so a WPA2/WPA3 router is still joined with WPA3-SAE. The report's "Security used" line is therefore not reliable; "Last negotiated Wi-Fi security" is.

Settings, trips, the fuel log and fuel totals are kept.
