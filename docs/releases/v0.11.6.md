EngineLink 0.11.6: returns to the router by itself.

- **Back to the router by itself.** After a fallback to standalone (no router address within 120 seconds), EngineLink keeps its own Wi-Fi on and listens for the saved router: after 2 minutes, then every 10 minutes. When the router is there, it switches back to router mode (its own Wi-Fi turns off, as router mode should). If that fails again, the 120-second guard brings standalone back and the next look waits longer (20, 40 … up to 120 minutes), so it never hops back and forth. It does not switch while someone is using the app on EngineLink's own Wi-Fi (a request in the last 2 minutes). Pressing Connect still switches right away. The look is asynchronous; the board keeps serving meanwhile.
- Diagnostics → Wi-Fi says when EngineLink will look for the router next.
- EngineLink only serves HTTP, in standalone and router mode alike. Browsers that try HTTPS first on a name such as `enginelink.local` get refused straight away and fall back to HTTP; opening the board by its IP address (`http://192.168.4.1` standalone, the router address in router mode) avoids that. WPA3-SAE (and WPA2/WPA3 mixed) is supported as before.

Settings, trips, the fuel log and fuel totals are kept.
