# EngineLink v0.9.3 — Wi-Fi stability and full USB reinstall

## Scope

This is a new ESP32-S3 application build using the **same Marine Precision UI**
and existing engine, trip, logging, fuel and settings functions. It addresses
reported AP disconnections and incorrect or disappearing 2.4 GHz router lists.
No J1708 TX or NMEA 2000 transmit policy has been relaxed.

## Fixes

- **Network discovery:** copy scan results before the ESP32 Wi-Fi driver's scan
  buffer can be cleared by another router search or reconnect. Keep the
  strongest 30 *unique* SSIDs from the entire scan, not merely the first 30 raw
  radio entries, and sort them by signal level. Keep the previous list visible
  while a new scan is active; report errors and timeouts explicitly.
- **Shorter off-channel time:** reduce active scan dwell from 300 ms to 120 ms
  per channel to shorten disruption of EngineLink's own access point. A
  single-radio ESP32-S3 cannot scan other channels without brief interruptions.
- **HTTP responsiveness:** cap the diagnostic download-speed test at 32 KiB
  instead of sending an entire 512 KiB payload in one synchronous request.
  This reduces the main HTTP server stall on slow links.
- **Diagnostics:** distinguish the longest normal UI request from long
  transfers and show scan status and number of unique discovered networks.
- **Full USB installer:** explicit user-facing warning that the merged
  8 MB image replaces internal settings, fuel history and filesystem data.
  The device's removable microSD card is not erased by USB flashing.

## Installation and data

From the desktop Chrome/Edge USB installer at
https://kaelor9.github.io/EngineLink/ select the compiled **v0.9.3** image.
This is a **destructive reinstall**, including on previously configured boards.
Disconnect the J1708 and NMEA 2000 engine networks before initial tests.
After flashing, join `EngineLink` (default password `12345678`) and open
`http://192.168.4.1`. Change the default password in Settings.

Do **not** use an old or cached website manifest. Confirm that the installer
shows version 0.9.3 before selecting Install.

## Validation matrix

### Automated

- Arduino ESP32-S3 application compilation (N8R8, OPI PSRAM, 8 MB).
- Embedded UI JavaScript validation and generated header consistency.
- Merged image and OTA app-image descriptor checks in the Pages workflow.
- Existing source and host regression tests in GitHub Actions.

### Required on the real PCB (not simulated by CI)

1. With all engine and NMEA buses disconnected, perform the complete USB
   reinstall and power-cycle. Confirm that the `EngineLink` Wi-Fi beacon
   appears and `http://192.168.4.1` loads.
2. On iPhone, open Settings > Boat router and scan repeatedly; verify each
   scan terminates, shows unique 2.4 GHz SSIDs and preserves the previous
   list during refresh.
3. Run download-speed test multiple times, switch between Trip, Settings
   and Diagnostics and watch *Missed here*, phone drops and slow UI requests.
4. Connect to a valid 2.4 GHz router, power-cycle and confirm both own AP
   and router access. Disconnect/disable the router and verify AP recovery
   within the configured guard period.
5. Confirm the status LED, SD detection and engine UART receivers work without
   unsolicited J1708 transmissions. Verify isolated power rails before
   reconnecting the engine and NMEA buses.

**Limits:** a successful compile does not prove Wi-Fi RF stability, antenna
matching, power integrity or compatibility with every router and phone.
Firmware remains alpha until tested on the owner's actual board.
