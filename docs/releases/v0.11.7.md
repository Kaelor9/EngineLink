EngineLink 0.11.7: WPA2 first, so the router connection does not lock up.

- **WPA2 first on WPA2/WPA3 routers.** A field report on 0.11.6 (Zyxel EX3600-T0, WPA2/WPA3 mixed) showed the cause of the endless green/blue light: after about an hour on WPA3-SAE the link dropped with code 209 (the router did not answer a WPA3/PMF SA Query), and from then on every new WPA3 login failed (codes 2, 4, 202) for hours, also after fallbacks and automatic returns. EngineLink now logs in with WPA2 (PMF off), which a mixed router allows; there is no SA Query then. It uses WPA3-SAE only when the router requires it (codes 210/211, or WPA2 never getting in), and remembers what works. If WPA3 ever drops with code 209, it logs in again with WPA2 at once instead of failing for two minutes. No change to the router is needed.
- **The automatic return no longer waits forever** while the app is open on EngineLink's own Wi-Fi: after 30 minutes in standalone it looks for the router anyway.
- The network report shows which security EngineLink uses and how often it switched.

Settings, trips, the fuel log and fuel totals are kept.
