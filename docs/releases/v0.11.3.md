# EngineLink v0.11.3 — WPA3 SAE compatibility and realistic Wi-Fi speed test

The owner's Zyxel EX3600-T0 in WPA2/WPA3 transition mode repeatedly reported AUTH_EXPIRE (2), WPA handshake timeout (15) and AUTH_FAIL (202). The same board connected cleanly to the router when it was switched to WPA2-PSK, and to an iPhone hotspot. **This release is a firmware-side compatibility attempt, not yet a verified WPA3 fix.**

## Changes

- Configure the ESP32-S3 station **before its first association** with `WPA3_SAE_PWE_BOTH`, a cleared SAE H2E identifier, and PMF capable (optional). Support for WPA3-only and WPA2/WPA3 mixed-mode is preserved; no forced WPA2 downgrade.
- Start association only after the explicit ESP-IDF station configuration is applied. If that setup fails, use Arduino's original connection path so the router attempt is never skipped.
- Include the **security actually negotiated** (WPA2/WPA3) and SAE setup status in the network report. The small Diagnostics page shows it alongside current IP/RSSI.
- A connected router no longer displays a historical failed-login message as a current error; correct ESP32 driver reason 2 (authentication timeout).
- The 32 KiB HTTP speed test now sends full TCP-MSS-sized chunks (1460 bytes), and yields only periodically, instead of forcing a task delay after every 256-byte write.

## Testing still required on real hardware

1. While Zyxel remains WPA2-only, update the device and verify Wi-Fi and HTTP responsiveness; measure the speed test.
2. Restore WPA2/WPA3 mixed mode and attempt connection, while keeping recovery AP intact. Copy `/api/network-report` after success or rescue. Verify `Last negotiated Wi-Fi security` reports WPA3-SAE if it succeeds.
3. Test WPA3-only on a suitable router separately; do not claim support as verified until this succeeds.
4. Check that standalone mode, scanner, browser UI and engine read-only acquisition are unaffected.

The 120-second recovery fallback and stored Wi-Fi credentials are unchanged. No personal SSIDs or passwords are embedded in firmware.
