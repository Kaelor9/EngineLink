EngineLink 0.13.0: the firmware is split into one file per area.

- The 5,900-line main file is now: `EngineLink.ino` (global state, setup and loop), `model.h` (all data types and constants), and one file per area: engines, fuel, trips, diagnosis, storage, Wi-Fi, web API, network report, downloads and exports, updates, LED, NMEA 2000 and engine test. The C++ helpers (WPA3 switch, transmit power, TCP window, crash info) have proper headers.
- The code itself is moved, not changed: the firmware is the same size and does the same.
- Comments describe what the code does instead of the history behind it. The source checks in CI read the whole firmware and find functions by name, so they no longer break when code moves.

Settings, trips, the fuel log and fuel totals are kept.
