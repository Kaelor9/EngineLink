EngineLink 0.12.1: reports a working connection.

- With a GitHub token saved, EngineLink also files its network report once after each start (including after an update) when the router connection has held for 2 minutes. So every new version reports by itself whether it connects, without pressing anything. Reports after a router loss or a web-server restart, and "Send report now", work as before.

Settings, trips, the fuel log and fuel totals are kept.
