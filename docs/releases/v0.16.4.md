# EngineLink 0.16.4 — app page reachable on the own Wi-Fi

With 0.16.3, phones joined EngineLink's own Wi-Fi, but the app page never answered: the report showed 1 phone connected and 0 HTTP requests.

- **Fix:** the web server listens on the Wi-Fi again once it is up. The simple Wi-Fi in 0.16.2 had left this out.
- **Wi-Fi log:** phones joining and leaving EngineLink's Wi-Fi are now written to the Wi-Fi log (`wifi log`).
- **Power save:** Wi-Fi power save is switched off on the own Wi-Fi.

Not yet tested on the board.
