# EngineLink 0.16.3 — Wi-Fi log on the SD card, serial commands

- **Wi-Fi history on the SD card.** The SD card is kept when the firmware is reinstalled over USB, so the history survives.
  - `/WIFI.LOG` gets a line for every Wi-Fi event: start, own Wi-Fi on or off, router joined, dropped.
  - `/WIFIREP.TXT` gets the full Wi-Fi report 2 minutes after start, then every 30 minutes.
  - Each file is capped at 256 kB. Older text moves to a `.OLD` file.
- **Serial monitor commands** (115200 baud, end with Enter):
  - `wifi` — the Wi-Fi report now
  - `wifi log` — the Wi-Fi events saved on the SD card
  - `wifi reports` — the Wi-Fi reports saved on the SD card
  - `wifi save` — save the Wi-Fi report to the SD card now
  - `status`, `help`
- **Own Wi-Fi at 8.5 dBm.** On many ESP32-S3 boards, phones can see the network but not join it at full transmit power. Lowering the power is the usual fix.

Not yet tested on the board.
