EngineLink 0.12.9: more data on the way at once, and a simpler Wi-Fi page.

- The real speed limit through a router: the Arduino libraries let each connection have only 5744 bytes (4 packets) on the way before waiting for the phone's answer. On EngineLink's own Wi-Fi the phone answers in a few ms, so that is enough for hundreds of kB/s. Through the router every answer took 50-80 ms (0.12.7 and 0.12.8 reports), which caps downloads below about 90 kB/s, and with only 4 packets out one lost packet stalls the connection for a second or more. EngineLink now raises this for each connection right after it opens: 8 packets for pages and files, 16 for the speed test. The bundling test in 0.12.8 showed no real difference (46 vs 60 ms), so it was not the cause.
- The Wi-Fi section in Diagnostics is simpler: connection, speed test, transmit power and the network report. Counters, frame bundling, the ping test and the GitHub token are under Advanced.
- An auto sweep that is left half-way (the app closed) no longer leaves the transmit power on the step it was trying: after 90 seconds it goes back to the chosen one.

Settings, trips, the fuel log and fuel totals are kept.
