# EngineLink 0.16.2 — simple Wi-Fi

The phone still could not join EngineLink's own Wi-Fi with 0.16.1. The Wi-Fi code behind the app is now simple: about 140 lines instead of about 1,000.

- **Own Wi-Fi:** "EngineLink" at 192.168.4.1, using the name and password from the settings.
- **Router:** EngineLink joins the boat router and reconnects by itself. If the router can't be reached in 2 minutes, EngineLink turns its own Wi-Fi on. It tries the router again every 10 minutes, as long as no phone is connected to its own Wi-Fi.
- **The app is unchanged.**

Everything else is as in 0.16.0.

Not yet tested on the board.
