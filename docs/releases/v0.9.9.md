# EngineLink v0.9.9 — Wi-Fi discovery reliability

## Fixes

- **Staged 2.4 GHz scanning:** discover channels 1–13 asynchronously, at 220 ms active listen time per channel. Return to the SoftAP channel briefly between channels rather than keeping the radio off-channel for one continuous sweep.
- **Do not change Wi-Fi mode inside the HTTP scan request.** EngineLink acknowledges the browser first, then starts scanning.
- Collect up to 60 unique visible SSIDs across all channels, keeping the strongest BSSID signal for each name. Preserve partial results while additional channels are scanned.
- Show current scan channel, partial network count, scan duration, and failed channels.
- Never silently substitute old scan results for an empty/failed new scan.
- A short discovery period may temporarily enable the STA interface on the standalone SoftAP. The STA does **not** connect to any router, and normal operation remains exclusive standalone AP or router STA.
- Remove dead synchronous scan functions, preventing accidental re-introduction of multi-second blocking scans.
- Keep the existing Marine Precision UI and all other EngineLink features.

## Installation

Only use the USB installer at https://kaelor9.github.io/EngineLink/ once it displays **v0.9.9**. Full USB installation overwrites internal configuration and history (not the external SD card).

## Hardware validation

On the actual ESP32-S3 PCB:
1. Connect an iPhone directly to the standalone EngineLink network at http://192.168.4.1.
2. Open **Settings → Boat router** and scan repeatedly. Observe channels 1–13, result counts and any scan failures.
3. Compare against the router SSIDs visible in iPhone Wi-Fi settings. Only **2.4 GHz visible SSIDs** can appear; 5 GHz and non-broadcast/hidden SSIDs are excluded by design.
4. Ensure the iPhone stays connected and the web UI remains responsive.
5. Connect to a selected router. EngineLink's own SSID must disappear; the router must issue an IP and http://enginelink.local should load where multicast DNS is supported.
6. Enter an invalid password and verify rescue AP returns after the configured two-minute retry window.

**Caution:** CI compilation and static checks are not a substitute for testing Wi-Fi performance and router authentication on the PCB.
