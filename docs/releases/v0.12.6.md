EngineLink 0.12.6: full speed through the router.

- Report #74 (0.12.5): power save off, 802.11n, no lost pings, yet every ping to the router took 60-150 ms and 32 KB took 3.8 s. The cause was in EngineLink itself: in router mode the main loop read signal, channel and IP from the Wi-Fi driver on every pass, about 1000 times a second. Each read waits for the driver's own task, so every packet through the router had to queue behind them. On EngineLink's own Wi-Fi this code does not run, which is why standalone was fast. These values are now read once a second.
- Frame bundling (A-MPDU) is on again by default: turning it off in 0.12.5 did not help. The switch stays under Diagnostics → Wi-Fi.

Settings, trips, the fuel log and fuel totals are kept.
