EngineLink 0.13.1: engine reports to GitHub, and a calmer app.

- Engine report: with a GitHub token saved, EngineLink files an "Engine report" after each trip (and when you tap "Send engine report"). It shows how well both engines were read: frames and errors, read requests and replies, how fast the engine answers, values held back by the plausibility check or never answered, data coverage, fuel per engine, events, and the full diagnostics data. A trip that ends at sea is reported when EngineLink is back on the router. It can be switched off. Reports hold engine data and trip times, never a position, router name or password.
- Diagnostics has one "Reports" section for the token, the engine report and the Wi-Fi report (they used to sit under Wi-Fi → Advanced).
- Events: a short explanation of what marking a moment does, "Mark this moment" instead of "Something's odd", and "Mark all as seen" only when there is something new.
- Settings: the line between "Time zone" and "Internet time" is back, and "Phones on EngineLink Wi-Fi" is only shown on EngineLink's own Wi-Fi.

Settings, trips, the fuel log and fuel totals are kept.
