EngineLink 0.12.11: nothing to set, a clear hint when the router's channel is the problem, and a crash fix.

- Transmit power is always chosen by EngineLink (ping test at start, "Test speed" afterwards). The transmit power setting and "Find the best transmit power" are gone from the app; Advanced only has the counters and the GitHub report token.
- 0.12.10 report: the larger send window now works (118 connections raised), yet speed swung from 5 to 104 kB/s at every strength, pings to the router lost up to 40 % at -44 dBm, and pings to the internet went through the same slow hop. That is a busy 2.4 GHz channel on the router (channel 1, shared with another network), not something the board can change. When the signal is strong but the router answers slowly, the Wi-Fi card now says so and which channel to set the router to.
- Crash fix: the 0.12.9 crash (core dump: pbuf_free while reading a web request) came from restarting the Wi-Fi driver while a web connection still held received data. Web connections are now closed before the driver restarts.

Settings, trips, the fuel log and fuel totals are kept.
