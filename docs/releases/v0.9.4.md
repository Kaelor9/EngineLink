# EngineLink v0.9.4 — Wi-Fi setup stability

**Status:** Alpha firmware; USB web installer build. Not yet hardware-verified on the custom PCB.

## Changes
- Keep ESP32-S3 in AP+STA mode from startup even when using standalone EngineLink Wi-Fi. The station interface stays disconnected unless a router is configured.
- Wi-Fi network scan no longer changes AP/STA radio mode to enable scanning, reducing the risk of the phone being disconnected during scans.
- Keep the same recovery behavior when the router cannot be reached.
- Reduce synchronous HTTP read timeout from 2000 ms to 1000 ms to limit the time a stalled HTTP request blocks the main server.
- Retain the current Marine Precision app UI, engine monitoring and data API.

## Installation
- **Full USB install:** Open https://kaelor9.github.io/EngineLink/ in desktop Chrome or Edge, use a USB-C data cable and the Install button when the site displays **0.9.4**. This writes the full merged 8 MB image and **overwrites all previous internal settings and history**; external microSD data is not erased.
- Disconnect J1708 engine buses and NMEA 2000 for first flash and bench validation; do not connect to live engine systems until the interface and isolated supply checks pass.
- After reboot, join the EngineLink access point and open http://192.168.4.1 . First verify standby AP, repeated Wi-Fi scans, web UI navigation, and an optional router connection.

## Validation
- GitHub Actions compilation and static validation are necessary but **not** proof of radio reliability or engine hardware safety.
- Validate AP visibility, scan consistency, phone join/drop counts, and device resets on the real ESP32-S3 board before relying on it aboard the boat.
