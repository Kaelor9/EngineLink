EngineLink 0.11.10: more patience with slow WPA3 logins.

- **More patience with a router that is slow to let EngineLink in.** Device report #53 (sent by the board itself): on WPA3-SAE the Zyxel needed 110 seconds and 14 attempts (codes 2/4/202) before EngineLink was let in, just under the 120-second limit after which EngineLink falls back to its own Wi-Fi. When the router is clearly there but slow (codes 2, 4, 15, 202, 204), EngineLink now keeps trying for up to 5 minutes. When the router is not found at all, it still falls back after 120 seconds.
- Report #53 also showed the web server healthy in router mode (427 requests, no self-check misses) and the GitHub report path working.

Settings, trips, the fuel log and fuel totals are kept.
