# EngineLink 0.15.0 — simpler, steadier Wi-Fi

Wi-Fi now follows a few fixed rules instead of many automatic adjustments.
No router setting needs to change (automatic channel, mixed WPA2/WPA3).

## Router

- **Reconnecting.** After a lost or failed connection EngineLink tries again
  after 1, 2, 4 and 8 seconds, then every 15 seconds, and only once the last
  attempt has ended, so a login in progress is never cut off. This replaces
  the Arduino library's retry every 1.6 seconds (field reports #95/#126), the
  30-second nudge and the special case for code 209.
- **Rescue is no longer remembered.** If the router cannot be reached for two
  minutes, EngineLink's own Wi-Fi comes back as before. Then:
  - EngineLink looks for the router every minute, a tenth of a second on its
    last channel and on all channels every fifth time.
  - It goes back by itself as soon as the router is there and the app has
    not been used for a minute, or after 10 minutes at the latest.
  - Every start in router mode tries the router first. Before, one rescue
    (for example a router that starts slower than EngineLink when the boat
    is switched on, #95) kept every later start away from the router for 10
    minutes to 2 hours.
- **Fixed transmit power, really applied.** The automatic choice never took
  effect: setting the country put the power back to 20 dBm (#95, #125,
  #130), and its test never completed while the app was open. EngineLink now
  uses 19.5 dBm, set after the country, and checks that the driver uses it.
  The board has worked at that power in every report.
- **No radio tests in the background.** The ping and channel test now runs
  only after "Test speed" on the router, and changes nothing on the radio.
- **The board's own web server self-check no longer counts as app use**, so
  an idle phone on EngineLink's Wi-Fi does not hold back the return to the
  router.

## Diagnostics

- The Wi-Fi event list shows a repeated event once with a count ("x31 until
  +4751s"), so the first cause of an outage stays in the list.
- The Wi-Fi report adds:
  - reconnect attempts;
  - rescue looks and returns;
  - the router's last known channel;
  - the transmit power the driver really uses;
  - the longest time of each part of the main loop and the engine task's
    longest wait;
  - a section for EngineLink's own Wi-Fi (phones joined and left, watchdog
    restarts).
- The app no longer asks you to change the router's channel when the channel
  is busy.

## Also in this version

Standalone Wi-Fi, engine reading, trips, fuel figures and updates work as
