EngineLink 0.12.10: the bigger send window actually works, and Wi-Fi tunes itself.

- 0.12.9 meant to let 8-16 packets be on their way per connection, but the report said "0 connections raised": the web servers use dual-stack IPv6 sockets, which the code did not recognise. Fixed; the report shows how many connections were raised.
- "Test speed" is the only thing to press. On the router it tries every transmit power twice with a 64 KB download (high to low, then low to high) and keeps the fastest on average, staying on the current one unless another is clearly (15 %) better. One 32 KB test per strength swung too much to pick from.
- Frame bundling is no longer a setting and is no longer tested: both tests in the field showed only noise, and each switch cost a reconnect (the "deliberately left" entries in the reports). The driver's normal setting is used. Transmit power (Auto by default) is under Advanced.
- The app reloads itself when the board has new firmware, so the page always matches it.
- The network report lists recent restarts and, after a crash, where it happened (task, address and backtrace from the core dump).

Settings, trips, the fuel log and fuel totals are kept.
