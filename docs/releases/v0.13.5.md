# EngineLink 0.13.5 — reliable trip summary download

- Send the small Trip summary CSV as a standard fixed-length HTTP response, not via the streaming deflate/chunked transport.
- Preserve the downloadable CSV filename and no-store cache header.
- Leave the larger second-by-second and raw engine exports unchanged.

**Validation:** CI compilation and source checks required before publication. Verify in Chrome and on the iPhone home-screen app. This addresses one plausible source of failed tiny downloads; a network-wide fault is not ruled out.

**Update:** Use the in-app Wi-Fi update to retain existing settings, trips and logs.
