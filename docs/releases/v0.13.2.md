# EngineLink 0.13.2 — iPhone navigation and Wi-Fi password fields

- iPhone Add to Home Screen: stop extending the app below the visible viewport; size the five-tab bottom navigation with enough **content height** as well as safe space for the home indicator. Trip, Economy, Tank, History and Engines stay visible and tappable.
- Router selection: keep the focused Wi-Fi password/SSID input mounted while asynchronous live-data and scan updates render. This prevents iOS keyboard dismissal, text loss and cursor jumps while typing.
- Password fields: disable unwanted text corrections/capitalization; constrain the selected network input to the available width on narrow phones.
- Motor polling, decoding, trip logging, calibration, storage and Wi-Fi connection logic are unchanged.

**Compatibility:** ESP32-S3 EngineLink revision 1; OTA from v0.13.1 preserves settings, trip logs and fuel data. The iPhone home-screen layout and keyboard behaviour still require a real-device check. This is alpha firmware; a successful build does not certify every KAD300 parameter, zero frame loss, tank-to-tank fuel calibration or NMEA 2000.

The release workflow regenerates `firmware/EngineLink/ui.h` from `firmware/ui/app.html` before building. For local Arduino builds run `python3 tools/build_ui.py` first.
