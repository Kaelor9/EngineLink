EngineLink 0.11.5: router mode without name look-ups.

- **Router mode: the app no longer depends on the .local name.** Opened as `http://enginelink.local`, every request needed a multicast name look-up (mDNS). On Windows and through many routers that takes seconds or fails (`DNS_PROBE_FINISHED_NO_INTERNET`), which looked like a slow, unstable board: blank or late pages, "Reconnecting", and a speed test that never reached the board (0 bytes written). Now, as soon as EngineLink reports its router address, the app sends all requests (live data on port 81, speed test on port 82, downloads and reports) straight to that IP address. If the address changes, the app finds the board again by name and switches to the new address.
- Settings → Boat router suggests bookmarking the IP address and reserving it in the router (DHCP reservation).
- No firmware network behaviour changed. **Not yet tested on the board.** If direct-IP access is also slow, the cause is elsewhere (see the README handover); the PowerShell tests there separate the two.

Settings, trips, the fuel log and fuel totals are kept.
