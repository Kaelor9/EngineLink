# EngineLink v0.9.6 — Two exclusive Wi-Fi modes

EngineLink now operates in **one normal Wi-Fi mode at a time**:

- **EngineLink Wi-Fi (factory default):** `WIFI_AP`, own SSID, `http://192.168.4.1` or `http://enginelink.local`.
- **Connect to a router:** `WIFI_STA`, EngineLink's own SSID is **off**, accessed through the router-assigned IP or `http://enginelink.local`.
- Selection survives reboot. If a saved router connection cannot acquire an address within 45 seconds, EngineLink enters and persists a rescue AP mode until the user requests a fresh connection.
- Switching back to EngineLink Wi-Fi via Settings disconnects from the router.
- Both modes use HTTP port 80, no HTTPS server or forced HTTP-to-HTTPS redirection.
- Network scans on standalone AP may briefly enable the STA interface only during scanning; normal operation never runs AP and STA together.
- Preserves the existing Marine Precision UI and all engine features; clarifies Wi-Fi mode transition prompts in Settings.
- mDNS responds on the active network; router mDNS requires local multicast reachability.

## Installation
Fresh USB installation at https://kaelor9.github.io/EngineLink/ once the site displays **0.9.6**. The full 8 MB merged image replaces internal NVS, configuration and history. External microSD is untouched. Disconnect engine networks and NMEA 2000 for the initial bench test.

## Verification
Use the hardware to verify:
1. After factory flash only EngineLink Wi-Fi is visible; its IP and `enginelink.local` load the web UI.
2. Scan networks, connect to router, and verify EngineLink's own SSID vanishes.
3. On the same router, access via assigned IP and `http://enginelink.local`.
4. Disconnect in Settings: the router connection ends, EngineLink SSID returns.
5. Configure an unreachable router: recovery AP returns after 45 seconds.
6. Check Diagnostics request latencies and packet/drop counters in both modes.

**Alpha firmware:** A successful compile is not an on-board test, nor proof that any live marine bus connection is safe.
