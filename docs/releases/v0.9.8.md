# EngineLink v0.9.8 — Robust router setup and standalone recovery

## Defined operating modes
- **Standalone (factory default):** EngineLink broadcasts its own 2.4 GHz Wi-Fi access point and serves its web UI at http://192.168.4.1 or http://enginelink.local.
- **Connect to a router:** Select a visible 2.4 GHz SSID and provide its password. Once the acknowledgement has been sent, EngineLink stops broadcasting its own access point and switches to router-only WIFI_STA, serving the identical UI via the router-assigned IP and http://enginelink.local when mDNS multicast is supported.
- **Failure fallback:** The device performs asynchronous Wi-Fi association attempts about every 20 seconds over a full 120-second window. If it cannot obtain a router IP, it returns to standalone AP and persists rescue state across resets, rather than immediately retrying the unreachable router forever.
- **Successful connection:** Router-only mode remains active across resets; the user can explicitly switch back to EngineLink Wi-Fi from Settings.

## Changes from v0.9.7
- Increase the router-association retry window from 45 seconds to two minutes.
- Show router attempt count in diagnostics.
- Increase cached network scan capacity from 30 to 60 unique 2.4 GHz SSIDs (the ESP32-S3 cannot scan 5 GHz).
- Ensure open wireless networks receive an empty password, even after selecting an encrypted network.
- Keep the existing Marine Precision visual design and engine functionality.

## Installation and hardware verification
Use the full USB web installer at https://kaelor9.github.io/EngineLink/ **only once it shows v0.9.8**. A fresh full install overwrites NVS/settings/internal history. Disconnect J1708 and NMEA 2000 for the first bench test.

1. After flashing, verify the EngineLink SSID exists; open http://192.168.4.1.
2. Scan for nearby 2.4 GHz SSIDs and select the intended router.
3. Verify EngineLink's own SSID disappears after connecting, and the router issues an IP address.
4. Join the same router on the phone and open the device's IP or http://enginelink.local.
5. Test an incorrect password and verify fallback EngineLink SSID appears after the full retry window.
6. Repeat with the correct password and reboot in router mode; the device should rejoin without enabling the standalone SSID.

**Hardware status:** Compiling and unit tests do not verify Wi-Fi performance on the actual PCB.
