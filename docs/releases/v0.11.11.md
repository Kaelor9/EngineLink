EngineLink 0.11.11: WPA3 login with Hunting-and-Pecking.

- **WPA3 login with Hunting-and-Pecking by default.** The 0.11.10 report showed a whole boot without a single successful login to the Zyxel: 56 WPA3-SAE attempts timing out (codes 2/4/202, the router not answering the login frames). EngineLink had always used the newer Hash-to-Element (H2E) method whenever the router offered it. It now uses Hunting-and-Pecking first, switches to H2E after a session that never got in, and keeps the method that works. The report shows the method ("WPA3 login method").
- This replaces 0.11.7's "WPA2 first", which had no effect: the ESP32 Wi-Fi library in use always joins a WPA2/WPA3 router with WPA3.
- Not yet tested on the board. If neither method gets in, setting the router's 2.4 GHz network to WPA2-PSK (or WPA2/WPA3 with WPA2 for 2.4 GHz) is known to connect within seconds.

Settings, trips, the fuel log and fuel totals are kept.
