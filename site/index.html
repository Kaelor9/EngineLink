DESIGNED FOR REAL USE

Built around fuel insight.

The interface is designed to remain clear at a glance, with advanced diagnostic tools available when needed. Features described below are planned, not yet production-ready.

01 / MEASURE

Fuel efficiency

Per-engine and total L/h, followed by L/nm analytics when actual engine fuel data and speed are verified.

02 / RECORD

Journey history

Preserve each engine-running segment through stops, without requiring manual start/finish actions.

03 / CONNECT

Flexible networking

Direct EngineLink Wi-Fi or an existing boat router. Internet is not a requirement for local use.
