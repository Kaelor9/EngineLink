ENGINE LINK / ISOLATED FIRMWARE EXPERIMENT

ASYNC LAB v3 firmware

This is an fully asynchronous ESPAsyncWebServer and WebSocket speed/diagnostic experiment with OTA recovery. It is not validated on your hardware. It does not replace the normal EngineLink release.

USB full flash erases internal data

The ESP32-S3 merged 8 MiB image overwrites NVS and LittleFS including Wi-Fi settings, calibration and trip history. Disconnect J1708 and NMEA 2000 before first testing. The diagnostic baseline is NOT feature-complete.

Install experimental firmware via USB

Use Chrome or Edge on a computer, with an ESP32-S3 USB data cable.

Checking whether a test image was compiled and published…

For configured boards, prefer the smaller app-only OTA binary through EngineLink Settings → Firmware. It is safer for preserving stored data. Return to normal EngineLink installer.
