# Development experiments

This folder contains historical Lab v1.1 sketches and the newer Lab v1.2 with connection-recovery improvements. All are bench-only firmware and diagnostics. These sketches are not tested production firmware or verified engine fuel-rate decoders.

Never transmit on a live engine J1708 bus. Verify both isolated 5V supplies with their respective grounds and open SJ1/SJ2 before connecting to actual engines.

The older development sketch can be obtained from the project starter archive until its source is committed separately.
